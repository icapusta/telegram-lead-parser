🤖 AI Telegram Monitor: Умный парсер чатов с GPT-фильтрацией
Автоматизированная система мониторинга Telegram-каналов и групп в реальном времени.

Проект представляет собой микросервис на Python (Telethon), который «слушает» поток сообщений, фильтрует их по ключевым словам и передает на AI-анализ в n8n. 
Итогом является мгновенное уведомление о релевантных событиях (вакансиях, лидах) с детальной информацией об отправителе.

🚀 Возможности
Real-time Monitoring: Работает как Userbot, мониторит любые открытые чаты и каналы, в которых состоит пользователь.

Двухуровневая фильтрация:
Hard Filter (Python): Первичный отсев по ключевым словам (например, Python, n8n, remote).
AI Analysis (n8n + GPT-4o-mini): Интеллектуальный анализ контекста. Отличает реальную вакансию от рекламы, курсов или спама.
Метаданные: Извлекает не только текст, но и User ID, Username отправителя, название чата и прямую ссылку на сообщение.
Микросервисная архитектура: Полностью упаковано в Docker. Легко масштабируется и деплоится.
Безопасность: Все чувствительные данные (API_ID, HASH, WEBHOOKS) вынесены в переменные окружения (.env).

🛠 Технический стек
OS: Ubuntu 22.04 LTS
Core: Python 3.10 + Telethon (Asynchronous event loop)
Orchestration: n8n (Workflow Automation)
AI Engine: OpenAI GPT-4o-mini (via n8n)
Containerization: Docker & Docker Compose

⚙️ Архитектура решения
Service tg-monitor: Контейнер с Python-скриптом. Поддерживает постоянную сессию Telegram. При совпадении ключевых слов формирует JSON-пейлоад.
Webhook: Данные отправляются POST-запросом в n8n.
n8n Workflow:
Принимает JSON.
Отправляет промпт в ChatGPT: "Является ли это сообщение вакансией для Python разработчика?".
Если True — форматирует сообщение и отправляет уведомление в личный Telegram.

📦 Установка и запуск
1. Клонирование репозитория

```Bash
https://github.com/icapusta/telegram-lead-parser.git
cd telegram-lead-parser
```

2. Настройка переменных окружения
Создайте файл .env на основе примера:

```Bash
cp .env.example .env
```
Отредактируйте .env, вставив свои данные (получить API ключи можно на my.telegram.org):

```
TG_API_ID=12345678
TG_API_HASH=your_telegram_api_hash
TG_PHONE=79001234567
N8N_WEBHOOK_URL=https://your-n8n-domain.com/webhook/endpoint
```
3. Запуск через Docker Compose
```Bash
docker compose up -d --build
```
4. Авторизация (первый запуск)
При первом запуске необходимо ввести код подтверждения от Telegram. Запустите контейнер в интерактивном режиме:

```Bash
docker compose run --rm telegram-lead-parser
```
Введите номер телефона и код. После успешной авторизации сессия сохранится в папке data/, и последующие перезапуски будут автоматическими.

📝 Пример JSON payload (отправляемый в n8n)
```
JSON
{
  "text": "Ищем Python разработчика на удаленку...",
  "chat_title": "Python Jobs Global",
  "sender_id": 123456789,
  "sender_username": "@hr_manager",
  "link": "https://t.me/python_jobs/1024",
  "date": "2025-12-21 14:30:00"
}
```

Замените ключевые слова в файле listener.py
```
# --- КЛЮЧЕВЫЕ СЛОВА ---
KEYWORDS = [
'ключевое слово1','ключевое слово2'
]
```

🐢 Подробная инструкция (Для новичков с VPS)
Этот гайд для тех, кто купил чистый VPS (или сервер с предустановленным n8n) и хочет запустить парсер рядом.

Шаг 1. Подготовка

Вам понадобятся данные от Telegram API.
Зайдите на my.telegram.org.
Авторизуйтесь по номеру телефона.
Перейдите в API development tools.

Создайте новое приложение (можно ввести любые данные).
Скопируйте App api_id и App api_hash.

Шаг 2. Скачивание проекта на сервер
Зайдите на свой сервер через терминал (SSH) или консоль хостинга.

Создайте папку для бота и скачайте файлы:

```Bash
git clone https://github.com/icapusta/telegram-lead-parser.git
```
Зайдите в папку проекта:

```Bash
cd telegram-lead-parser
```

Шаг 3. Настройка конфигурации (.env)
Нам нужно создать файл с настройками, который "не виден" для посторонних.
Создаем файл .env из шаблона:

```Bash
cp .env.example .env
```
Открываем его для редактирования:

```Bash
nano .env
```

Заполняем своими данными:
TG_API_ID — цифры, которые вы получили на my.telegram.org.
TG_API_HASH — длинная строка оттуда же.
TG_PHONE — ваш номер (например, 79991234567).
N8N_WEBHOOK_URL — ссылка на ваш n8n.

Если n8n на том же сервере: Создайте в n8n workflow с триггером "Webhook", выберите метод POST и скопируйте Test URL (или Production URL). Вставьте его сюда.

Нажмите Ctrl+O -> Enter (сохранить) и Ctrl+X (выйти).

Шаг 4. Запуск контейнера
Теперь прикажем Docker собрать и запустить нашего робота.

```Bash
docker compose up -d --build
```
Docker скачает Python, установит библиотеки и запустит сервис. Если всё ок, вы увидите зеленые надписи Started.

Шаг 5. Авторизация (Самый важный шаг!)
При первом запуске скрипт не знает, что это вы. Нужно ввести код подтверждения.
Запускаем бота в ручном режиме:

```Bash
docker compose run --rm telegram-lead-parser
```

Скрипт попросит ввести номер телефона (если не указали в .env) и код подтверждения, который придет вам в Telegram. Введите его.
Если у вас стоит пароль (2FA), введите и его.
Когда увидите надпись "Signed in successfully..." или "Запускаем парсер...", нажмите Ctrl+C, чтобы выйти.
Теперь сессия сохранена в папке data/. Бот будет работать автоматически.

Шаг 6. Финальный перезапуск
Чтобы убедиться, что бот работает в фоновом режиме:

```Bash
docker compose restart telegram-lead-parser
```
Проверить, что всё работает, можно командой:

```Bash
docker compose logs -f telegram-lead-parser
```
(Выход из логов — Ctrl+C).
