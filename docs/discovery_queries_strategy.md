# Discovery Query Strategy

## Goal
Найти Telegram-сообщества, где регулярно появляются запросы на:
- разработку
- CRM/автоматизацию
- интеграции (1С, amoCRM, Bitrix24, API, webhook)

и автоматически проверять их исторические сообщения на лиды.

## Приоритет источников
1. Telegram internal search (через Telethon `contacts.SearchRequest`)
2. Поисковики (`site:t.me ...`)
3. TGStat (поиск сообществ и каналов, извлечение `t.me` ссылок)

## Сегменты с наибольшей конверсией
1. Владельцы бизнеса / CEO / предприниматели
2. Руководители продаж (РОП, коммерческие директора)
3. Digital-агентства и интеграторы как партнерский канал
4. Вертикали с повторяемыми болями: бьюти, онлайн-школы, медицина

## Анти-шум (что отсекаем)
- Сообщения, где автор предлагает свои услуги (self-promo)
- Продажа лидов/контактов
- Резюме/портфолио без запроса на подрядчика
